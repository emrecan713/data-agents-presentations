Layout: title (directive `_class: title`). Then # Title, a subtitle paragraph and an author/date paragraph. The author line sits at the bottom of the slide.

Layout: agenda. A numbered Markdown list after a ## heading.

Layout: default (no class). Add a `_footer` directive comment for sources.

Layout: columns. Wrap each column in <div>...</div> inside <div class="columns">. Leave a blank line after each opening <div> and before each closing </div>.

Layout: process. Use <ol class="process"> with one <li> per step and the step name in <strong>. Prefer this over a picture of a diagram: it needs no alt text and stays editable. Colour variants: blue, red, yellow, black. Text on coloured slides stays black.

Layout: box. Classes: box, box white, box yellow, box outline. Colour carries no meaning on its own: say in words which box matters.

Layout: figure. Short alt text in ![...](...), visible caption in <figcaption>. Figure description: Bar chart with four categories on the horizontal axis and counts from 0 to 20 on the vertical axis. A = 12, B = 19 (highlighted in yellow), C = 7, D = 15. B is the largest category and C the smallest.

Layout: free-form visual. A `style scoped` block styles only this slide; use your own class names and the --chart-* colours. The svg element carries role="img" and an aria-label. Figure description: Example data, not research results. Line chart over weeks 1 to 4, vertical axis 0 to 30. Series A (solid blue line) rises steadily: about 10, 18, 24 and 30. Series B (dashed red line) stays roughly flat: about 15, 16, 14 and 16.

Layout: picture. Keywords bg, right, 40% are read by Marp; the rest of the bracket text is the description. Use `bg left:40%` only when the picture must be on the left.

Layout: table. Keep a header row; it is announced with each cell.

Layout: quote. The heading is hidden visually but lets screen-reader users navigate. Keep quotations verbatim and give their context.

Layout: section-header. Combine with black, blue, red or yellow.

Layout: statement. One paragraph, at most two lines.

Layout: code. Fenced code blocks wrap long lines.
